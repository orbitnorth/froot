CORE CAPABILITIES

Built for Performance, Engineered for Ergonomics

⚡

Monomorphic Context

Preserves fixed V8 Hidden Classes. Never mutates object prototypes with setPrototypeOf, ensuring TurboFan inlining never degrades.

🛡️

Standard Schema Validation

Universal runtime validation conforming to the ~standard specification. Works with Zod, TypeBox, ArkType, and Valibot seamlessly.

🚨

RFC 9457 Problem Details

Machine-readable, standard HTTP API problem details for validation errors and exceptions via application/problem+json.

Async Onion Middleware

Natural await next() execution flow without callback hell or verbose lifecycle hooks. Measure timing and mutate headers on unwinding.
